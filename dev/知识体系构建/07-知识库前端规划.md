### 2.3 chatStore 变更

```typescript
// stores/chatStore.ts — Actions
updateSessionKnowledgeBases: (sessionId: string, knowledgeBases: string[] | null) => void

// 实现（与 updateSessionTargets 同构）
updateSessionKnowledgeBases: (sessionId, knowledgeBases) => {
  set(state => ({
    sessions: state.sessions.map(s =>
      s.id === sessionId ? { ...s, knowledge_bases: knowledgeBases ? JSON.stringify(knowledgeBases) : null } : s
    ),
  }))
  sessionsApi.updateSession(sessionId, {
    knowledge_bases: knowledgeBases ? JSON.stringify(knowledgeBases) : null,
  }).catch(() => {})
}
```

### 2.4 RightPanel 知识库挂载区

位置：在"帮手"区块之后、"GoalPanel"之前。

```tsx
// RightPanel.tsx — 新增 state
const [showKBPicker, setShowKBPicker] = useState(false)
const [allKBs, setAllKBs] = useState<KnowledgeBase[]>([])

useEffect(() => {
  fetchKnowledgeBases().then(setAllKBs).catch(() => {})
}, [])

// 解析当前挂载
let knowledgeBases: string[] = []
if (session.knowledge_bases) {
  try { knowledgeBases = JSON.parse(session.knowledge_bases) } catch { knowledgeBases = [] }
}
const mountedKBs = allKBs.filter(kb => knowledgeBases.includes(kb.id))
const availableKBs = allKBs.filter(kb => !knowledgeBases.includes(kb.id))

// 更新函数
const updateKB = (ids: string[]) => {
  updateSessionKnowledgeBases(session.id, ids.length > 0 ? ids : null)
}

// 渲染
{/* ── 知识库 ── */}
<div className="rp-section">
  <div className="rp-section-title" style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}>
    <span>{t('知识库')}</span>
    <button
      className="helper-add"
      title={t('挂载知识库')}
      onClick={() => setShowKBPicker(v => !v)}
    >+</button>
  </div>
  {mountedKBs.length === 0 ? (
    <div style={{ fontSize: 'calc(11px * var(--ui-font-scale))', color: 'var(--ink-faint)' }}>
      {t('无挂载知识库')}
    </div>
  ) : (
    <div className="helper-grid">
      {mountedKBs.map(kb => (
        <div key={kb.id} className="helper-item" title={kb.description}>
          <span className="helper-avatar">📚</span>
          <span className="helper-name">{kb.name}</span>
          <span
            className="helper-del"
            onClick={() => updateKB(knowledgeBases.filter(id => id !== kb.id))}
            title={t('移除')}
          >×</span>
        </div>
      ))}
    </div>
  )}
  {showKBPicker && (
    <div className="helper-pick">
      {availableKBs.length === 0 ? (
        <span style={{ fontSize: 'calc(11px * var(--ui-font-scale))', color: 'var(--ink-faint)' }}>
          {t('无更多可添加知识库')}
        </span>
      ) : availableKBs.map(kb => (
        <span
          key={kb.id}
          className="tag"
          onClick={() => { updateKB([...knowledgeBases, kb.id]); setShowKBPicker(false) }}
        >
          {kb.name}
        </span>
      ))}
    </div>
  )}
</div>
```

## 6. 视觉规范

### 6.1 RightPanel 知识库挂载区

复用现有 `helper-grid` / `helper-item` / `helper-pick` 样式，与帮手完全一致：

```
📚 产品手册库  ×        ← helper-item（📚 替代角色头像）
📚 FAQ库       ×
[+ 挂载知识库]           ← helper-add 按钮
```

hover 时显示 description tooltip。

### 6.2 知识库管理页（P2）

- 三栏比例：左 220px / 中 1fr / 右 380px
- 左栏背景 `var(--surface1)`，中/右栏背景 `var(--canvas)`
- 文档列表行高 48px，支持 hover 高亮
- 上传区虚线边框，拖入时高亮

### 6.3 检索调试（P3）

- 配置区使用表单布局（label + input 横排）
- 结果卡片使用 `surface1` 背景 + `border`
- 分数用颜色梯度（0-5 灰，5-10 黄，>10 绿）
