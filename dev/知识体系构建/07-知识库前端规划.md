## 3. 数据模型对接（前端视角，以后端为准）

### 3.1 后端 API 面（F1 起点，路由待后端实现）

```
GET    /api/knowledge/bases                → KnowledgeBase[]
POST   /api/knowledge/bases                → 创建（name/description/path）
DELETE /api/knowledge/bases/:id            → 删除（级联：文件/分块/索引/绑定）
GET    /api/knowledge/bases/:id/files      → 目录树 + 文档列表（含状态聚合）
GET    /api/knowledge/bases/:id/files/:path/content → normalized md 全文
DELETE /api/knowledge/bases/:id/files/:path        → 删除文件（保留原件？按 02 删除规则）
POST   /api/knowledge/bases/:id/upload     → FormData 批量上传（F2 起，F1 可仅列目录）
```

### 3.2 前端类型（types/knowledge.ts 新建）

```typescript
export type KnowledgeDocStatus = 'pending' | 'converting' | 'indexing' | 'indexed' | 'error'

export interface KnowledgeBase {
  id: string
  name: string
  description: string
  rootPath: string            // 后端 06：rootPath 绝对路径
  createdAt: number
  updatedAt: number
  // 聚合统计（后端计算，前端展示）
  docCount: number
  pendingConvert: number
  pendingIndex: number
}

export interface KnowledgeFile {
  id: string
  kbId: string
  relPath: string             // 子目录/文件名.md（目录树依据）
  type: 'md' | 'txt' | 'html' | 'docx' | 'pdf' | 'xlsx' | 'pptx' | ...
  status: KnowledgeDocStatus
  activeVersion: string | null
  versionCount: number
  chunkCount: number
  tokenCount: number
  error?: string              // error 时的原因（含 unsupported_ocr 明确提示）
  anchor?: string             // 来源锚点展示串（F2 起）
}

export interface KnowledgeDocContent {
  content: string             // normalized md
  sourceAnchor?: string
}
```
