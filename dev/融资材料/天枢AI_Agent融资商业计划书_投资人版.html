02 · PROBLEM

AI 能回答，
但难以负责到底

真实工作需要状态、权限、失败恢复、完成标准与长期资产，而不只是下一段文本。

典型断点现状业务后果
任务连续性断线、刷新或跨会话后状态容易丢失任务半途而废，用户反复交代
工具可靠性缺少审批、重试、检查点和结果验证高风险动作不可控，难进入生产业务
长期目标对话围绕单轮回答，缺少计划与证据闭环无法承担研究、运营、开发等复杂任务
资产沉淀提示词、人格、技能、记忆散落在各平台迁移成本高，组织知识无法复用
数据与成本云端黑盒、固定模型、平台绑定敏感数据顾虑，推理成本缺乏主动权
聚焦原则：早期不做“万能助手”，先围绕高频、可验证、能节省明确工时的任务包建立留存与付费。

04 · AGENT ASSET

角色即资产，
不是一段提示词

身份、关系、记忆、技能、工具、审批策略和视觉资源共同构成可运营的数字员工。

创

创建

定义 Soul、User、Memory、模型与风险边界。

强

增强

绑定技能、工具、工作区、事件和执行模式。

运

运行

每次任务产生可回放的 Run、事件、结果与成本数据。

沉

沉淀

将最佳角色与流程导出为团队模板或行业任务包。

商业意义：角色既是完成任务的专业能力载体，也是人格、记忆、形象、动作和皮肤的情感资产；同一角色可以同时产生订阅收入、数字商品收入与交易抽成。

角色多 Asset：把生成内容变成可使用、可交易的角色商品

角色会根据交谈、空闲、查询、工作、成功和异常等运行状态切换动态表现。多 Asset 结构让文生图、图生视频的结果不再是散落的媒体文件，而能被自动组织成可安装、可使用、可上架销售的完整角色资产包。

05 · DUAL VALUE ENGINE

一个 Agent，
两种不可替代的价值

“帮我完成”解决效率与结果，“愿意陪伴”解决关系、审美与身份表达，两者共享角色、记忆和模型基础设施。

PRODUCTIVITY VALUE

生产力价值：完成任务

用户为可靠结果付费，而不是为聊天次数付费。

  • 研究、文件、代码、运营和自动报告
  • Goal / Plan / 工具 / 审批 / 证据闭环
  • 专业技能角色包降低复杂任务门槛
  • 价值指标：成功任务数、节省工时、任务 ROI
EMOTIONAL VALUE

情绪价值：陪伴与表达

用户为“我喜欢的角色和空间”付费，形成高频互动与数字资产消费。

  • 角色多 Asset、表情、动作、语音与长期记忆
  • 文生图设计角色，图生视频生成多状态动作资产
  • 用户自用、换肤，或将原创角色上架二次销售
  • 游戏、动漫、虚拟偶像等 IP 联名与任务联动
市场参照：Character.AI 将更强模型、记忆、语音和聊天定制纳入 c.ai+；Kindroid 将高级模型、长期记忆、语音、视频头像与自拍作为订阅权益；Codex Dream Skin 已形成主题库、在线 Studio、社区投稿和一键换肤机制。它们共同证明：角色关系、视觉个性化和数字形象具备独立付费空间。
