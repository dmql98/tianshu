# 天枢市场（TianShu Market）PRD

> 版本 v0.1 · 2025 · 状态：Demo 阶段

## 1. 产品概述

天枢市场是天枢 AI Agent 平台的内置资产市场。用户可以在市场中**浏览、搜索、下载（安装）**社区资产，也可以**上传、分享**自己制作的资产。

**资产类型（8 类）**：角色（Character）、皮肤（Skin）、技能（Skill）、工具（Tool）、MCP 服务器、知识库（Knowledge Base）、主题（Theme）、图标包（Icon Pack）。

## 2. 目标用户

- **普通用户**：寻找现成角色/技能增强自己的 Agent，一键安装。
- **创作者**：打包发布自己的角色、技能、MCP 配置，获得下载量与评分。
- **进阶用户**：订阅主题/图标包/皮肤，个性化桌面端外观。

## 2.5 资产关联模型（核心机制）

资产之间是**弱关联（Association）**，不是强依赖——每个资产都可以挂一个**关联资产列表**，指向任意类型的其他资产：

```
角色 a                        技能 a
├── 皮肤 1 (v1.2.0)           ├── 技能 b (v0.9.0)
├── 皮肤 2 (v2.0.1)     或    └── MCP 1 (v2.2.1)
├── 技能 1~3 (各自带版本号)
├── MCP 1
└── 知识库 1
```

规则：
- **关联 ≠ 依赖**：不做版本约束校验，安装主资产不强制安装关联资产。
- 每条关联记录带**版本号**（关联项自身也是独立资产，可独立更新）。
- 详情页「关联资产」列表支持两种下载方式：
  - **一键下载全部**：批量安装列表中所有未安装的关联项；
  - **单项下载**：每行独立的安装按钮，按需安装。
- 关联项可能是市场内的独立资产（可点击跳转其详情页，安装状态与市场同步），也可能未上架仅被关联。
- 卡片展示关联标识：「关联 N 项资产」+ 关联类型图标。
- 卸载主资产不影响已安装的关联资产。

## 3. 核心功能与优先级

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 资产浏览 | 分类导航（8 类 + 推荐），卡片网格展示：封面、名称、作者、下载量、评分 |
| P0 | 搜索 | 关键词实时搜索，跨全部分类 |
| P0 | 下载/安装 | 卡片一键安装，按钮状态切换（安装 → 安装中 → 已安装） |
| P0 | 上传分享 | 上传弹窗：拖拽文件、选择资产类型、填写名称/简介/版本/标签 |
| P1 | 排序筛选 | 最热 / 最新 / 评分最高 |
| P1 | 资产详情 | 弹窗：截图、完整简介、版本、更新日志、安装按钮 |
| P2 | 精选 Banner | 顶部官方推荐位轮播 |
| P2 | 我的上传 / 我的下载 | 个人资产管理中心 |
| P3 | 评分评论 | 星级打分 + 文字评价 |

## 4. 用户交互路径

**下载资产**：进入市场 → 浏览推荐/切换分类 → （可选）搜索 → 点击卡片看详情 → 安装主资产 → 按钮变「已安装」。如需关联资产：在详情页「关联资产」列表单项安装，或点「一键下载全部」批量安装。

**上传资产**：点击「上传资产」→ 选择资产类型 → 拖拽/选择文件 → 填写元信息（名称、简介、版本、标签）→ 提交 → Toast 提示「提交成功，等待审核」→ 出现在「我的上传」。

**发现资产**：首页精选 Banner → 点击直达详情；或按排序（最热/最新）浏览。

## 6. 非功能性需求

- 桌面端优先（1440px 设计稿，最小适配 1024px），暗色主题与天枢桌面端一致。
- 分类切换模拟加载骨架屏；图片懒加载。
- WCAG AA 对比度；所有交互元素键盘可达。
- 审核机制：上传资产进入待审核队列，通过后上架（Demo 以 Toast 模拟）。

## 7. 设计方向

- **风格**：极客暗黑模式（Zinc 深灰骨架）+ 琥珀金品牌色（呼应「天枢」北斗星意象），毛玻璃弹窗、多层柔和投影、大圆角。
- **技术**：纯 HTML5 + Tailwind CDN + Vanilla JS，无构建框架。
