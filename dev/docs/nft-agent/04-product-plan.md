# 天枢「角色资产化」产品方案（v1 提案）

> 版本：v1 提案（2026-08-27）
> 定位：把天枢桌面 Agent 的角色与皮肤做成「可拥有、可分发、可选择性上链」的数字资产，建立角色付费与创作者生态。
> 一句话方案：**不做 NFT，做「角色资产化」——先卖皮肤与角色（Web2 数字商品），跑通付费后，再以联盟链收藏凭证（Web3-lite）作为可选加分项。**

| 参数 | 定稿值 |
|---|---|

| 边界 | 说明 |

## 一、目标与范围

### 1.1 目标
1. 验证「用户愿意为角色人格/皮肤付费」的核心假设（阶段一）。
2. 建立创作者生态：让用户能创作、打包、分享、销售角色资产（阶段一后期~阶段二）。
3. 以最低合规风险提供「所有权/收藏感」（阶段二，可选上链凭证）。

### 1.2 不在本次范围
- ❌ 不做二级市场 / 转售 / 回购 / 拍卖
- ❌ 不做虚拟货币结算
- ❌ 不做 PFP 式稀缺炒作叙事
- ❌ 不做版权资产证券化交易（需交易所资质，明确不进入）

## 二、目标用户与价值主张

### 2.1 目标用户（按优先级）

| 用户群 | 需求 | 付费意愿 |
|---|---|---|
| 天枢现有用户（开发者/效率人群） | 角色好看、有个性、能提升使用仪式感 | 中，习惯为工具付费 |
| 二次元/角色收藏爱好者 | 为角色形象、设定、限定皮肤付费 | 高（已验证市场） |
| 创作者/调教师 | 希望自己的角色/皮肤被认可、被使用、有收益 | 高（供给端） |
| 企业/团队 | 统一品牌形象角色、定制数字人助理 | 中高（B 端定制） |

### 2.2 价值主张
- 对用户：**「你的 Agent 不只是工具，是可以拥有的伙伴。」** 皮肤+人格+能力=独一无二的可运行角色。
- 对创作者：**「你的调教成果可以变成资产。」** 打包、署名、分发、获得回报。
- 对天枢：**「角色商店 = 增长引擎 + 创作者护城河。」** 竞品（Character.ai/星野）卖的是对话内容，天枢卖的是**可运行的生产力人格资产**——这是差异化护城河。

## 四、商业模型

### 4.1 结算模型（v1.1 更新：采用法币担保市场，替代原「积分」设想）

> 背景：原方案曾考虑「平台积分可流通结算」；经合规分析（见 08 文档），可流通积分在国内外均触发红线（国内非法金融活动/海外证券定性）。**改为法币担保市场（单一钱包）**：用户以人民币/美元买卖角色资产，平台提供托管担保与结算，按销量阶梯抽 5–13%；创作者收益走法币分账（¥20 起提）；**资产生成必须用钱包现金**（成本+20%，每账号首次免费）；天枢 API 按上游成本+5% 从钱包扣费；BYOK 自带 key 不经钱包。**不引入任何可流通代币。**

### 4.2 收入结构（目标构成）

| 收入来源 | 占比（预估） | 说明 |
|---|---|---|
| 市场交易服务费（抽成） | 35% | 用户间担保交易，销量阶梯抽 5–13%（1-3份13%/4-6份10%/7-10份8%/10+份5%，对标 Steam 市场） |
| 官方角色/皮肤销售 | 25% | 官方自营 + 创作者分成 |
| 模型 API 服务 | 15% | 调用天枢 API 按 token 从钱包扣费（**上游成本+5%，无免费额度**）；**BYOK 全用户开放**：自带 key 可接任意 OpenAI 兼容厂商（含 opencode go/zen），直连不经钱包、透传无限制 |
| 资产生成费 | 10% | 创建资产收取 **token 成本+20%**（**必须钱包现金**）；每账号首次生成免费一次 |
| 会员订阅（可选增值） | 10% | 资产库扩容、高级创作者工具、云端备份 |
| 企业定制 | 5% | 品牌形象角色/数字人助理定制 |

> 以上为方向性预估，具体比例以 M1 试点数据为准。

### 4.3 定价原则
- 低门槛高频（对标游戏皮肤 ¥1–¥30）而非高价低频（对标 PFP）。
- 价值锚定 = 视觉质量 + 人格完成度 + 能力增量 + 稀有度。
- 明确告知：**购买的是使用许可与收藏凭证，不是投资品**（合规要求，也是消费者信任基础）。
- 抽成透明：交易页明示服务费率与当前销量阶梯；**资产生成费 = 成本+20%，从钱包现金扣，每账号首次免费**；天枢 API = 上游成本+5%，从钱包扣费（无免费额度）；BYOK 自带 key 透传直连不经钱包。

### 4.4 成本结构（主要）
- 官方皮肤制作（美术/动画，可自研+外包+AI 辅助）
- 创作者分账与税务处理（代扣代缴）
- 支付渠道费（微信/支付宝/Stripe/Adyen）
- LLM token 采购成本（用户侧加价覆盖）
- 上链费用（阶段二，联盟链按量付费，可选）

> 结算细节、担保交易流程与合规边界见 **08-fiat-market-settlement.md**。

## 五、阶段路线（Roadmap）

| 阶段 | 周期（预估） | 目标 | 关键里程碑 | 退出/继续标准 |
|---|---|---|---|---|
| **M0 资产化基础** | 2~4 周 | 本地可打包/导入/导出角色资产 | `.tskin`/`.tchar` 导入导出可用；资产库页上线 | 完成即继续 |
| **M1 角色商店** | 4~8 周 | 验证付费意愿 | 首批 10~20 款官方皮肤上架；**付费转化率 ≥3%** 或首批销售额达预期 | 转化率 <1% → 复盘定价/选品，不盲目加量 |
| **M2 创作者生态** | 6~10 周 | 供给端自增长 | UGC 上架 100+ 款；创作者活跃 50+ | 创作者留存 <20% → 改进工具与分成 |
| **M3 轻量上链** | 4~6 周（前置合规 2~3 月） | 收藏凭证与差异化 | 备案完成；证书功能上线 | 备案受阻 → 上链无限期推迟，Web2 模式不受影响 |

> 关键原则：**M1 付费验证不通过，不启动 M2/M3**。上链始终是可选项，绝不让合规负担拖累核心功能。

## 六、风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 合规：金融化/炒作指控 | 🔴 | 全程「数字商品」叙事；禁二级市场/回购/虚拟货币；上链仅凭证（见监管报告红线清单） |
| 版权：皮肤/人格侵权 | 🟠 | 上架版权审核（官方自证+UGC 申报）；AI 生成素材来源留痕；侵权下架机制 |
| 需求：付费意愿不足 | 🟠 | M1 小批量试水，用转化率数据决策；定价对标游戏皮肤而非 PFP |
| 竞争：大厂（星野/豆包等）复制 | 🟡 | 差异化在「可运行生产力人格资产」，非纯陪伴；先发创作者生态 |
| 技术：资产包兼容性/迁移 | 🟡 | 格式设计保证与现有结构兼容；只增不删；导入校验+降级机制 |
| 未成年人/AI 内容合规 | 🟡 | 内容分级、AI 标识、敏感角色审核（详见监管报告） |
| 平台分成/支付资质 | 🟡 | 法币支付走合规渠道；虚拟商品销售按规范执行 |

## 七、验证标准（整体）

| 维度 | 验证标准 |
|---|---|
