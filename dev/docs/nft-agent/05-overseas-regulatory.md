# 天枢「角色资产化」海外监管环境调研（美国 / 欧盟 / 英国）

> 调研时间：2026-08-27
> 依据：美国 SEC 官网新闻稿（Stoner Cats 案 2023-178 全文已核实）、欧盟委员会 AI Act 官方页面（全文已核实）、Wikipedia（NFT 市场数据、Character.ai）、知识库（标注 [需复核] 项）
> 目的：支撑海外融资 BP 中的「合规策略」章节，并指导产品设计（避免在海外踩 NFT 证券化红线）

---

## 一、结论摘要

1. **海外没有「NFT 一刀切禁止」，但美国 SEC 用「证券法 Howey 测试」逐个执法**：凡是 NFT 发行伴随「二级市场转售、升值预期、团队能力背书」等投资暗示，就会被认定为「投资合同」= 证券，必须注册。Stoner Cats 案（已核实）是最近的标杆案例。
2. **合规设计原则（海外通用）**：卖「可使用、可收藏的数字商品 + 使用许可」，不卖「投资品」；不做二级市场/转售承诺/交易版税/升值暗示；上链仅作收藏凭证。这样在美欧英都不会落入证券监管。
3. **欧盟对「AI 角色」有明确的透明度义务（AI Act，2026-08 起适用）**：聊天机器人必须告知用户「你在与 AI 交互」，AI 生成内容须可识别。这对天枢做海外版是**必须前置**的合规项，也是 BP 中展示「团队懂监管」的加分点。
4. **2025 年美国 SEC 转向**：新领导层成立 Crypto Task Force、放缓对加密资产的执法（[需复核]），但证券法框架未变——保守设计依然是最稳路径。

## 二、美国：SEC 对 NFT 的执法框架

### 2.1 法律基础：Howey 测试
NFT 是否构成「证券」取决于**经济实质而非标签**。四项要件：①投入资金 ②共同事业 ③合理期待从他人努力中获利 ④获利来源于发起方/第三方的努力。

### 2.2 已核实案例：Stoner Cats（SEC Press Release 2023-178，2023-09-13）

| 事实 | 详情 |
|---|---|
| 发行 | 2021-07-27 向投资者发售 10,000+ 个 NFT，单价约 $800，35 分钟售罄，募资约 $8M |
| 违规点 | 营销突出「可在二级市场转售」「成功剧集将推高转售价」「好莱坞团队+知名演员背书」，并设置每笔二级交易 2.5% 版税、鼓励买卖 |
| 定性 | 违反《1933 年证券法》未注册发行 crypto asset securities（投资合同） |
| 处罚 | $1M 民事罚款、Fair Fund 退款机制、销毁全部库存 NFT、公开公告 |
| 官方表述 | 「无论标的物是海狸、龙猫还是动物 NFT，决定是否为投资合同的是发行的经济现实，而非标签」 |

> 对天枢的直接启示：**只要不在营销/机制中制造「转售升值预期」或「团队努力带来回报」，且不做二级市场与交易版税，就远离 Howey 红线。**

### 2.3 知识库案例：Impact Theory（[需复核]，2023-08）
- SEC 指控洛杉矶媒体公司 Impact Theory 以「Founder's Keys」NFT 进行未注册证券发行，募资约 $30M，和解罚金约 $6.1M（没收+利息+罚款），认定投资者被引导期待通过公司努力获利。

### 2.4 2024-2026 监管风向变化（[需复核]）
- 2024 年 Gensler 任内对加密/NFT 执法趋严；2025 年 1 月新政府上任后成立 **Crypto Task Force**，放缓部分执法、推动国会立法框架，Coinbase 等多项调查被撤销。
- 结论：监管态度在松动，但「未注册证券发行」的判例法没有改变。**对创业公司最稳的姿势：根本不让自己落入证券定义。**

### 2.5 对天枢的美国合规清单
- [ ] 商品定位：数字商品 + 使用许可（License），法币结算，无二级市场
- [ ] 禁止：转售承诺、升值暗示、交易版税、回购、投资话术（"earn/buy-back/appreciate"）
- [ ] 若上链：仅存 manifest 哈希与购买记录（凭证），不明示或暗示可交易
- [ ] 用户协议明确「购买的是使用许可与收藏凭证，非证券、非投资品」

## 三、欧盟：MiCA + AI Act

### 3.1 MiCA（加密资产市场法规，Regulation (EU) 2023/1114）[知识库，需复核]
| 项目 | 内容 |
|---|---|
| 生效时间 | 2023-06 通过；稳定币规则 2024-06-30 起适用；加密资产服务商（CASP）2024-12-30 起适用 |
| NFT 处理 | 第 2(3) 条及序言：**独特的、不可互换的加密资产（含数字艺术与收藏品）不适用 MiCA**；但「系列化/可互换化」的 NFT 集合、或拆分份额的 NFT 可能落入 |
| 对天枢意义 | 限量单件数字收藏品天然在 MiCA 范围外；若做成「同一皮肤 1 万份同质化销售」则需评估是否构成 e-money token/ART 等 |

### 3.2 EU AI Act（Regulation (EU) 2024/1689）——已核实（欧盟委员会官方页面）
| 时间点 | 义务 |
|---|---|
| 2024-08-01 | 生效 |
| 2025-02-02 | 禁止实践（如有害操纵/欺骗、利用弱势群体等）+ AI 素养义务 |
| 2025-08-02 | GPAI（通用大模型）透明度与版权义务 |
| **2026-08-02** | **透明度义务全面适用：聊天机器人须告知用户「在与机器交互」；AI 生成内容须可识别（deepfake 与公共信息类内容显著标识）** |
| 2027-12-02 / 2028-08-02 | 高风险系统义务（教育、就业、征信、关键基础设施等）——AI Omnibus（2026-07-27 生效）已延后并简化 |

> 对天枢的意义：
> - **AI 角色产品在欧盟核心义务 = 透明度**：角色必须明示「AI，非真人」；生成图片/视频需可识别标识。这是硬性义务，2026-08 起执行。
> - 天枢作为「生产力 Agent（非陪伴）」大概率**不落入高风险类别**（除非进入招聘/征信等场景），义务集中在透明度和内容标识。
> - AI Omnibus（2026-07-27 生效）新增禁止「生成非自愿性露骨内容/CSAM 的 AI 系统」（2026-12 生效）——角色内容审核需覆盖。

### 3.3 欧盟合规清单
- [ ] 角色对话界面明示「AI 角色」（符合 AI Act 透明度 + 深度合成精神）
- [ ] AI 生成图片/视频/音频加可识别标识（元数据或可见标识）
- [ ] 未成年人保护与内容分级（AI Act 禁止利用弱势群体操纵）
- [ ] 若发行同质化 NFT 集合，先做 MiCA 定性评估（建议直接规避，做限量单件凭证）

## 四、英国（FCA）[知识库，需复核]

| 项目 | 内容 |
|---|---|
| 加密资产推广 | 2023-10 起加密资产金融促销须经 FCA 授权人士批准，违规营销将受罚；主要针对「可投资的加密资产」，纯收藏 NFT 一般不落入 |
| NFT 定性 | 除非 NFT 具有特定投资属性（如收益权、证券化特征），否则不被视为 FCA 监管的特定投资 |
| AI 治理 | 英国主张「支持创新的原则式监管」（2024-2025 立场），暂未像欧盟立法，但对「AI 冒充真人/欺骗」持零容忍 |
| 对天枢意义 | 英国路径与美国类似：避免投资话术与二级市场；AI 角色需防冒充/欺骗 |

## 五、全球对比小结

| 司法区 | NFT 证券化红线 | AI 角色核心义务 | 天枢策略 |
|---|---|---|---|
| 美国 | Howey 测试，逐案执法（Stoner Cats 案为标杆） | 无联邦专门 AI 法，州层面零散 | 卖使用许可，无二级市场，无投资话术 |
| 欧盟 | MiCA：独特 NFT 豁免；同质化集合需评估 | AI Act 透明度（2026-08）+ 禁止实践 | 明示 AI 身份 + 内容标识；限量单件凭证 |
| 英国 | 非投资属性 NFT 一般不监管 | 原则式监管，禁冒充欺骗 | 同美国 |
| 中国（对照） | 联盟链+数字出版产品路径，禁金融化 | 深度合成标识+实名+备案 | 见《02-监管合规》文档 |
