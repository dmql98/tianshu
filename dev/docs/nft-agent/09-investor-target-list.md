# 天枢「角色资产化」投资人适配清单（投给谁合适）

> 调研时间：2026-08-27
> 依据：已核实公开事实（a16z 投资 Character.ai——Wikipedia 已核实）+ 行业知识库；**所有机构的最新投资方向与联系方式均标注 [需复核]**，投递前请逐一核实其最新 focus 与 open deal 状态。
> 结论先行：这个叙事（可拥有的 AI 角色 + 法币资产市场 + 创作者经济）最适合投给**「消费者 AI / Agent 商业化」和「游戏/数字内容经济」交叉型基金**；不建议投给纯 Crypto/NFT 基金（叙事不符）也不建议投给纯企业 SaaS 基金（不懂消费者资产）。

---

## 一、投资人匹配逻辑（先对齐标准）

一个基金适不适合投天枢，看四点：

| 匹配点 | 为什么重要 |
|---|---|
| 1. 投过 AI 角色/陪伴/消费者 AI | 赛道已验证，无需教育 |
| 2. 懂数字商品/皮肤/创作者经济 | 能看懂商业模式（Steam 逻辑） |
| 3. 接受「桌面产品 + 海外市场」 | 产品形态与出海路径 |
| 4. 不忌惮「内容/资产」叙事（但要反感 NFT 泡沫） | 叙事一致性 |

老板提到「即梦本身可能懂我在说什么，可能会给他背后的资本投 BP」——即梦（字节旗下 AI 创作产品）背后的资本/生态关系，对应的是：

| 机构 | 匹配逻辑 | 备注 |
|---|---|---|
| **真格基金 / 奇绩创坛** | 华人背景、AI 早期布局、懂中国团队出海 [需复核] | 若走华人 VC 路线 |
| **蓝驰创投 / 源码资本** | 消费+AI 早期 [需复核] | 国内 |
| **Monolith / 峰瑞等出海基金** | 关注中国团队全球化 [需复核] | — |
| **新加坡/香港家族办公室与基金** | 接受消费 AI + 东南亚市场 [需复核] | 若走 APAC 路线 |

> 说明：国内人民币基金对「数字商品/角色资产」接受度分化（部分仍把内容资产当监管敏感），建议优先走**美元/海外架构**，用海外主体融资；国内机构可作为战略/生态股东而非领投。

## 五、不建议投给的（叙事错配）

| 类型 | 原因 |
|---|---|
| 纯 Crypto/NFT 基金 | 我们刻意不做 token 经济，叙事冲突，估值逻辑也错位 |
| 纯企业 SaaS / 基础设施基金 | 不懂消费者资产与皮肤经济，尽调成本高 |
| 国内纯人民币基金（无海外架构） | 内容资产叙事在国内融资有监管不确定性 |

## 六、投递策略建议

1. **优先级排序**：a16z（Consumer/Games）→ Bitkraft → NFX/Lightspeed → 华人背景出海基金。
2. **每一家的 BP 微调**：
   - a16z：强调「Agent 商业化缺失层 + Character.ai 生态空白」；
   - Bitkraft/Griffin：强调「皮肤经济的 AI 版 + 创作者分成（Steam/Roblox 类比）」；
   - 华人基金：强调「中国团队做海外市场 + 桌面工具执行力」。
3. **配套材料**：3-5 分钟产品录屏（角色管理+皮肤系统+资产打包）优先于文字 BP；英文 BP（07）+ 一页 Executive Summary。
4. **融资路径建议**：Seed 优先走美国/新加坡美元基金；如走即梦背景资本，适合作为**产业方战略轮**（带渠道/生态资源），估值通常低于财务轮但资源价值高。
