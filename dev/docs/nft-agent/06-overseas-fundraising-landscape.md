## 一、结论摘要

1. **海外资本对「AI 角色/陪伴」赛道是真实热钱的**：Character.ai 2023-03 以 $1.5 亿融资拿到 $10 亿估值（a16z 等参与），2024-08 Google 以「技术授权+核心人才收购」方式接盘创始人；2025-2026 该赛道持续有融资与并购（[需复核] 具体新案例）。资本已用真金白银验证了「AI 角色」的稀缺性。
2. **但「纯 PFP NFT」叙事在海外已经死亡**：NFT 交易量从 2021 年 $170 亿崩到 2022 年下跌 90%+，2023-09 报告称 95% 藏品归零。海外投资人听到「NFT」第一反应是泡沫。**BP 里绝不能以 NFT 为主叙事**，要以「AI Agent 商业化/角色经济」为主叙事，NFT/上链只是可选的收藏凭证。
3. **天枢的差异化卖点海外投资人容易懂**：海外资本正在看「AI Agent 怎么赚钱」，天枢给出一个清晰答案——**Agent 即商品（角色/皮肤/技能打包销售）+ 创作者分成**，对标 Steam 皮肤经济 × Character.ai 角色生态 × Roblox 创作者经济。这三个参照系海外 VC 都熟。
4. **融资窗口判断**：2026 年海外 AI 融资整体回暖、但回归「有收入/有 PMF 的公司」；天枢有**已运行的桌面产品 + 已落地的角色/皮肤系统**（真实 traction），这是 seed/Pre-A 轮的强背书。

## 三、给天枢的定位建议（BP 叙事核心）

### 3.1 一句话定位（英文）
> **"Tianshu is the operating system for ownable AI characters — where your agent is not just a tool, but an asset you can own, customize, and trade."**

（天枢是「可拥有的 AI 角色」的操作系统——你的 Agent 不只是工具，而是可以拥有、定制、分发的资产。）

### 3.2 三个投资人熟悉的类比
| 类比 | 投资人理解 | 天枢对应 |
|---|---|---|
| **Steam 皮肤经济** | 玩家为虚拟外观付费已被验证 | 角色皮肤商店（立绘/动画/人格） |
| **Character.ai 角色生态** | UGC 角色+订阅变现 | 角色创作/打包/分享/分成 |
| **Roblox 创作者经济** | 平台抽成+创作者分成 | 四层角色资产 + 创作者工作台 |

### 3.3 与直接竞品的一句话差异
> "Character.ai sells conversations. Roblox sells worlds. **Tianshu sells the characters themselves — as runnable, ownable assets** (persona + capability + memory + skin), not just chat threads."

### 3.4 目标投资人画像（建议）
- 类型：关注消费者 AI / Agent 基础设施 / 数字内容经济的美国、欧洲、新加坡 VC；**避免**纯 Crypto/NFT 基金（叙事不符且拉低估值）
- 轮次：Seed / Pre-A（产品已运行、商业模式待验证）
- 决策语言：英文 BP（本套件已备） + 产品 demo（建议录屏：角色/皮肤系统操作演示）
