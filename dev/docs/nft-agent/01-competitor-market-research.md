# 天枢「角色资产化」竞品与市场动态调研

> 调研时间：2026-08-27
> 调研人：小红（天枢执行秘书）
> 说明：本报告基于可核实的一手来源（官网、Wikipedia、政府文件）与公开行业报道撰写。标注「[需复核]」的数据为行业内流传较广但未在本轮检索到权威出处的估计值，引用时请谨慎。

---

## 一、结论摘要

1. **「AI 角色付费」已被市场验证，但形态正在从「订阅」转向「内容+资产」**。Character.ai 用 $9.99/月订阅验证了角色聊天的付费意愿；星野（MiniMax）用社区+角色创作验证了 UGC 角色生态；2026 年 Character.ai 转向微短剧（c.ai Series）说明平台正在寻找订阅之外的第二曲线。
2. **「卖角色/皮肤本身」没有纯 NFT 的成功先例，但有大量近似的成功模型**：游戏皮肤（CS:GO/王者荣耀）、AI 角色社区的打赏与会员、数字藏品的「限量数字出版产品」合规路径。
3. **国内数字藏品行业已从 2021-2022 的爆发转入合规收缩期**：行业从「投机资产」共识转向「数字出版产品」定位（国家新闻出版署实验室《数字藏品应用参考》）。这为天枢提供了现成的合规语言和路径。
4. **天枢的差异化空间在于「可运行的人格资产」**——竞品都只卖视觉或只卖对话，没有一个把「人格参数 + 技能包 + 记忆 + 皮肤」打包成可运行资产。

## 二、竞品扫描

### 2.1 Character.ai（美国，角色对话鼻祖）

| 维度 | 实况 |
|---|---|
| 定位 | AI 角色聊天平台，用户可创建并发布角色 |
| 关键数据 | 2023-03 估值约 $10 亿（$1.5 亿融资）；2024-01 日访问约 350 万，用户以 16-30 岁为主 [Wikipedia] |
| 商业化 | 2023-05 推出 c.ai+ 订阅 $9.99/月（跳过排队、更快响应） |
| 重大动态 | 2024-08 Google 雇佣联合创始人 Noam Shazeer 并达成非独占技术协议；2025-10 宣布禁止 18 岁以下用户创建/对话角色；2026-07 推出 AI 微短剧 c.ai Series |
| 对天枢的启示 | ①订阅是基础盘但不是天花板；②未成年人合规是 AI 角色产品的必答题；③平台在往「角色 IP 内容化」演进——这正是天枢「角色即资产」叙事可以借力的方向 |

### 2.2 星野（MiniMax，国内）

| 维度 | 实况 |
|---|---|
| 定位 | MiniMax 基于自研大模型的沉浸式 AI 智能体社区，用户可创造、分享智能体 |
| 官网表述 | 「支持用户自由创造和分享 AI 智能体的社区平台」「原创角色或是分身伙伴」「定制工具+无限想象创造梦想中的羁绊」 [xingyeai.com] |
| 商业化 | 会员订阅 + 社区内容消费（打赏/礼物类） |
| 对天枢的启示 | UGC 角色创作+社区分发在国内跑通了；其角色定位偏「陪伴/剧情」，天枢角色偏「生产力/执行」，两者受众不同，冲突小 |

### 2.3 其他角色/数字人平台（简述）

- **Replika（美国）**：AI 伴侣订阅制（约 $20/月），验证了情感向高客单价。
- **猫箱/Talkie（字节/MiniMax 系）**：移动端 AI 角色应用，主攻泛娱乐聊天。
- **HeyGen / 硅基智能等数字人**：B 端视频数字人，卖「形象+配音」，不涉及人格资产。
- **GPT Store / 扣子 Coze / Dify**：Agent 市场，卖「工作流/技能」，几乎不卖「角色人格与皮肤」，且变现机制普遍薄弱（开发者分成落地缓慢）[需复核]。

### 2.4 皮肤/饰品参考市场（非 AI，但付费逻辑最接近）

- **CS:GO/CS2 饰品**：皮肤+交易市场，第三方平台年交易额达数十亿美元级别，玩家愿意为纯视觉付费并为稀缺性溢价 [需复核]。
- **王者荣耀皮肤**：腾讯财报显示皮肤是其核心变现手段之一，单款传说皮肤可贡献亿元级流水 [需复核]。
- **原神等二次元抽卡**：角色+外观付费，付费深度和 ARPPU 极高。
- 结论：**「为虚拟外观和虚拟角色付费」是已被反复验证的全球性行为**。

## 三、市场规模与趋势判断

1. **AI 伴侣/角色应用**：全球头部应用（Character.ai、Replika、Talkie）月活跃合计数千万级，付费以订阅为主 [需复核具体数字]。
2. **游戏虚拟商品**：全球游戏内购+虚拟商品市场是千亿美元级大盘，皮肤/饰品占大头 [需复核]。
3. **国内数字藏品**：2022 年平台超 700 家 → 2023 年起大批平台收缩/转型，头部（鲸探等）转向「数字文创+实体权益融合」。
4. **趋势**：纯视觉资产（PFP）退潮；「功能型数字资产」（能用、能玩、能提升体验）是下一阶段。天枢的角色皮肤兼具「视觉+功能（人格/技能）」双重属性，方向踩在趋势上。

## 四、对天枢的具体启示（竞品维度）

| 竞品已验证的 | 天枢应做的 |
|---|---|
| 用户愿意为 AI 角色订阅付费 | 角色/皮肤商店要有「免费+付费」双轨，付费给「稀缺+功能增量」 |
| UGC 角色创作能形成社区 | 皮肤/角色可分享、可导入导出，先形成 UGC 创作闭环 |
| 未成年人问题会成为监管与舆论焦点 | 内容分级、敏感角色审核、防沉迷设计必须前置 |
| 纯订阅有天花板，平台在内容化 | 天枢不靠订阅，靠「资产交易+增值服务」，避开正面竞争 |
| 游戏皮肤证明了「为视觉付费」 | 皮肤定价可参考游戏皮肤（低门槛高频），而非 PFP 的高价低频 |
