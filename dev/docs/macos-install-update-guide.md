# macOS 安装与更新说明（免签名版）

> 适用对象：macOS 用户（Apple Silicon / Intel 均可）。
> 本版安装包**未做 Apple 签名公证**（免费分发方案的取舍），因此**首次安装需要一次手动放行**；此后**所有版本更新均由应用内自动更新完成，无需再操作**。

---

## 一、选择正确的安装包（重要）

| 你的 Mac | 请下载 |
|---|---|
| Apple 芯片（M1 / M2 / M3 / M4…） | `TianShu-<版本>-mac-arm64.zip` / `.dmg` |
| Intel 芯片 | `TianShu-<版本>-mac-x64.zip` / `.dmg` |

> ⚠️ 在 Apple 芯片上误装 x64 包会走 Rosetta 翻译，运行明显变卡。判断芯片：左上角  → 关于本机 → 芯片一栏。

## 二、首次安装（只需这一次操作）

### 方式 A：右键打开（无需终端，推荐）

1. 解压 zip，把 `天枢.app` 拖入「应用程序」
2. **右键**点 `天枢.app` → 选「打开」
3. 弹窗提示"无法验证开发者"时，点「打开」即可启动
4. 之后双击就能正常打开

### 方式 B：终端命令（彻底清除隔离标记，更稳）

若方式 A 被拦或想彻底移除隔离标记，打开「终端」执行：

```bash
sudo xattr -rd com.apple.quarantine "/Applications/天枢.app"
```

> 该命令只需执行一次。之后正常双击启动。

> ❌ 不要执行 `sudo spctl --master-disable`——它会全局关闭系统安全校验，不推荐。

## 三、版本更新（之后再也不用手动操作）

**请使用应用内自动更新，不要每次去网页重新下载安装包。**

- 应用每启动 ~7 秒后自动检查新版本（之后每小时一次）；发现新版本会**后台自动下载**
- 下载完成后弹窗提示 → 点「安装并重启」→ 应用自动重启为新版本
- 整个过程**不需要任何终端命令、不需要再次放行**

为什么自动更新不用再放行：应用内更新是由应用自己下载并替换文件，**不经过 macOS 的下载隔离（Gatekeeper）流程**，新版本不会带上隔离标记。而"从网页重新下载安装包"一定会触发隔离，所以那是唯一需要重复操作的路径。

### 手动检查更新（可选）

「设置 → 更新」→「检查更新」→ 有新版即开始后台下载。

## 四、兜底：自动更新失败时

（极少见：网络受限 / 更新服务器不可达）

1. 手动从官网/GitHub 下载新版安装包
2. **照旧按上面的「首次安装」步骤放行一次**（右键打开或 xattr 命令）
3. 老版本数据不受影响（同一数据目录，自动继承）

---

## 附：给维护者的发布要点

- **两条通道，缺一不可**：
  - **官网下载页** → 放 `dmg`，面向首次安装/手动升级（dmg 不能自动更新）
  - **应用内自动更新** → 走 `zip`（electron-updater macOS 只支持 zip 载荷），每次发版必须把对应架构的 zip 连同 `latest-mac.yml` 同步发布到更新目录（`https://www.tianshuapp.tech/updates`）
- **每次发版必须同时发布 `mac-arm64` 和 `mac-x64` 两个 zip**（arm64 是 Apple 芯片，x64 是 Intel + Rosetta 兜底），并更新官网页面的 `latest-mac.yml`
- `electron-builder.yml` 的 mac target 保持 `[dmg, zip]`；**zip 是自动更新的载荷，必须有**；dmg 只是给用户手动入口
- **不要给 `mac.identity` / 签名相关配置做改动**：当前 Electron 构建默认生成 ad-hoc 签名，这是未签名分发能在 Apple 芯片上运行的必需前提（ad-hoc 保证二进制有效，xattr 才放行得动）
- 发布说明/下载页务必放本指南，引导用户走「应用内自动更新」，避免每次手动下载 dmg
- 若未来购买 Apple Developer 账号并配置签名+公证（`notarize: true`），用户首次安装的放行步骤自动消失，其余不变
