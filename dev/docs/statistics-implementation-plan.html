价格匹配优先级

1. provider + model 精确匹配     → 用该模型的 hourly_prices
2. provider + model 通配匹配     → 用 "deepseek*" 规则
3. "*" 通用 provider + model     → 兜底服务商的价格
4. "*" 通用 provider + 通配      → 最终兜底
5. 无匹配                        → 免费（费用=0）

费用计算公式

// 取调用时间的小时
hour = new Date(created_at).getHours()  // 0-23

if (pricing.is_free === true) {
  actual_cost  = 0
  savings      = Σ (token[t] × ref_hourly_prices[hour][t] / 1_000_000)
} else {
  actual_cost  = Σ (token[t] × hourly_prices[hour][t] / 1_000_000)
  savings      = 0
}

// token[t] ∈ { usage_input, usage_output, usage_cache_hit, usage_cache_miss }
