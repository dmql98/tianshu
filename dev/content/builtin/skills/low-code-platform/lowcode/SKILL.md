# 低代码平台

先判断用户当前目标，再只激活完成任务所需的子技能：

- 了解实体模型或项目结构：`lowcode/overview`
- 审查已有项目：`lowcode/analyze`
- 从需求生成整体蓝图：`lowcode/designer`
- 创建设备与协议配置：`lowcode/device`
- 定义变量与数据类型：`lowcode/variable`
- 创建自动化流程：`lowcode/flow`
- 创建页面和数据绑定：`lowcode/frontend`

复杂的新项目先激活 `designer`，再根据蓝图逐个激活具体实体技能。不要一次加载全部子技能。
