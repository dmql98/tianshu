# UZI 股票分析

根据用户目标选择子技能：

- 全面研究、估值或投资备忘录：`uzi/deep-analysis`
- 多流派观点、评审团或投资人方法论：`uzi/investor-panel`
- 龙虎榜、席位和游资行为：`uzi/lhb-analyzer`
- 财务造假、治理、退市或交易陷阱：`uzi/trap-detector`

全面研究可先激活 `deep-analysis`，仅在工作流明确需要时再增加其他子技能。不要一开始加载全部四个技能。
