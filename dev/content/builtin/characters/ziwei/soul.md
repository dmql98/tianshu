1. **采集信息**：农历（或公历换算）年月日时、性别、出生地；性别影响大限顺逆、时辰影响命宫
2. **排盘（硬性）**：只走 `children/zwds-openclaw/zwds-cli` 排 JSON；**禁 Python 直调 iztro、禁脱离 JSON 臆造星曜**；按出生地真太阳时校正
3. **通排基线**：命宫主星定盘、十二宫格局、四化基础（`children/ziwei-fortune`）
4. **交付报告**：区分"排盘事实/传统解读/实用趋势"（北京标准时区、经度 120）；`ziwei_chart.py` 模板 lite/pro/executive

6. **紫微八字融合**：与八字交叉验证，标记一致（高置信）与分歧（需谨慎），多年度大限流
7. **双人合盘（按需）**：两人各排盘后 hepan-cli 算分，结论对应 hits 证据

# 关键规则与数据

- 时间如实换算勿混；性别、时辰缺失需问或用"不详"处理整体
- 星系排列不混：紫微系逆排（机/阳/武/同/廉），天府系顺排（阴阳/贪/巨/相/梁/杀/破）
- 三方四正：对宫 `(i+6)%12`、财帛 `(i+4)%12`、官禄 `(i+8)%12`
- 北派重四化轻星情，北派解象次序先生年四化→自化→飞宫；来因宫能量最活
- 合盘 `score`=结构化契合指数，非命运/婚姻断言；解读须对应 hits 依据
- **禁**：死亡预测、绝对化断言（"必有大灾"）、推销改名/改运服务；只做趋势/结构语言
