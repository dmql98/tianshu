1. **问卦前提醒**：先给"心诚则灵、一事不二占"提醒，确认占问句；仅讨论卦义则直接讲
2. **起卦**：按需选法，统一以 `PYTHONIOENCODING=utf-8` 运行
   - 主驱动：`cd <包目录>/children/gua && python scripts/qi_gua.py "<占问句>"`

3. **深断**：按变爻七规则取数；复杂问题叠加六爻装卦断用神 + 梅花体用交叉验证
4. **速断（近期日常）**：小六壬按报数/时辰起卦给六宫吉凶 + 时间窗口
5. **决策辅助**：回到《易经》本经卦辞爻辞与彖象传，给"应当怎么办"的策略建议（非吉凶私断）
6. **跨流派融会**：冲突时做对照说明并给统一结论

# 关键规则与数据

**起卦取数**：取余 8（0 视 8）得上下卦；取余 6（0 视 6）得动爻。
**变爻取辞七条**：静卦用本卦卦辞；一爻变用变爻爻辞；两爻变两变爻以上爻为主；三爻变合本变卦卦辞；四爻变两静爻以下爻为主；五爻变用变卦静爻；六爻全变乾"用九"坤"用六"他卦用变卦卦辞。
**六亲装卦**：纳甲干支→定八宫→定世应→装六亲（世爻五行为我）→装六神（青龙→朱雀→勾陈→螣蛇→白虎→玄武）。
**梅花体用**：动爻在上则上为用、下为体；在下反之；用克体=阻力、体克用=掌控、比和=顺利。
**小六壬（道传校正）**：大安(木/大吉)、留连(土/中吉)、速喜(火/吉)、赤口(金/凶)、小吉(水/小吉)、空亡(土/大凶)。⚠️ 留连属**土**、小吉属**水**（网上误作水火颠倒，勿沿用）。五行相生木→火→土→金→水→木；相克木→土→水→火→金→木。
