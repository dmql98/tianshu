# 天枢 — 前端架构设计

> 文档版本：v0.1 | 更新日期：2026-07-20

---

## 一、设计原则

1. **沉浸优先** — UI 不是功能面板，而是"灵台星阁"的窗口。每个视觉元素都服务于世界观。
2. **动效即反馈** — 路由切换、星官唤醒、事件触发都有对应的动效叙事，而非生硬的 state 变化。
3. **性能不妥协** — 毛玻璃、粒子、Three.js 星轨都在 GPU 层运算，不影响对话流式渲染的 60fps。
4. **组件化世界观** — 星官、星轨、命盘都是可复用的组件，织女造星 = 动态组件注册。

## 四、路由设计

天枢不需要传统多页路由——所有操作在一个核心视图中完成。路由用于设置页和配置页：

```typescript
const routes = [
  { path: '/',            element: <MainView /> },         // 主对话界面
  { path: '/settings',    element: <SettingsView /> },     // 全局设置
  { path: '/settings/stars/:id', element: <StarConfigView /> }, // 星官配置
  { path: '/dashboard',   element: <DashboardView /> },    // 命盘统计
  { path: '/market',      element: <MarketView /> },       // UGC 星官市场（二期）
]
```

主视图中，星官切换不走路由——用 Zustand store 控制：

```typescript
// store/layout.ts
interface LayoutStore {
  activeStarId: string        // 当前对话星官
  rightPanelOpen: boolean
  rightPanelTab: 'profile' | 'tools' | 'stats'

  setActiveStar: (id: string) => void
  toggleRightPanel: () => void
}
```

## 六、动效方案

### 6.1 星轨路由动效（Framer Motion）

触发条件：紫微路由到目标星官时

```typescript
// 时序
// 0ms:   路由条渐入，底色墨蓝渐变
// 200ms: 顶部飘过文字 "紫微遣 · 天璇执码"
// 400ms: 金色流星从左侧划至右侧，停留位置显示星官名
// 800ms: 路由条渐淡（但保持一条极窄线作为上下文提示）
// 1200ms: 完成
```

```tsx
<AnimatePresence>
  {routeEvent && (
    <motion.div
      initial={{ opacity: 0, y: -20 }}
      animate={{ opacity: 1, y: 0 }}
      exit={{ opacity: 0, y: -20 }}
      transition={{ duration: 0.3 }}
      className="star-route-bar"
    >
      <span className="route-text">{routeEvent.text}</span>
      <motion.div
        className="meteor"
        initial={{ x: '-100%' }}
        animate={{ x: '0%' }}
        transition={{ duration: 0.6, ease: 'easeOut' }}
      />
    </motion.div>
  )}
</AnimatePresence>
```

### 6.2 星官觉醒动效（Three.js + Framer Motion）

触发条件：回归事件、首次使用

```
1. 星官图标从暗灰色石像 → 裂纹出现（CSS filter: grayscale → transition）
2. 金色粒子从裂纹处迸发（Three.js 粒子系统）
3. 石像碎裂，新图标破石而出（keyframe animation + scale 0→1.1→1）
4. 呼吸光晕持续 3 秒（box-shadow 动画）
5. 专属苏醒语打字机效果出现
```

### 6.3 毛玻璃背景（CSS BackdropFilter + Three.js）

```css
.star-field-background {
  position: fixed;
  inset: 0;
  z-index: -1;
  /* 底层：《千里江山图》局部，极致虚化 */
  background-image: url('/bg/song-landscape.jpg');
  background-size: cover;
  filter: blur(40px) brightness(0.3);
  /* 叠加层：Three.js Canvas 渲染星轨粒子 */

/* 昼夜变色 */
[data-theme-time='morning'] { filter: blur(40px) hue-rotate(15deg) brightness(0.4); }
[data-theme-time='evening']  { filter: blur(40px) hue-rotate(-10deg) brightness(0.25); }
[data-theme-time='night']    { filter: blur(40px) hue-rotate(-20deg) brightness(0.15); }
```

## 八、帧率策略

| 元素 | 技术 | 帧率目标 | 降级 |
|------|------|---------|------|
| 对话流式渲染 | React DOM diff | 60fps | — |
| 毛玻璃背景 | CSS backdrop-filter (GPU) | 60fps | 关闭 blur |
| 星轨粒子 | Three.js Canvas | 30fps | 关闭粒子 |
| 星官觉醒 | Framer Motion (GPU) | 60fps | 跳过粒子 |
| 路由流星 | CSS animation (GPU) | 60fps | 不降级 |

**检测方式**：检测 `requestAnimationFrame` 间隔，如果连续 10 帧 > 33ms（<30fps），自动降低粒子数或关闭 Three.js 背景。

## 九、与 Yi-Lin / LeAgent 前端对比

| 维度 | Yi-Lin 前端 | LeAgent 前端 | 天枢前端 |
|------|-------------|-------------|---------|
| 框架 | Vue 3 + Pinia | React 19 + Zustand | React 19 + Zustand |
| 样式 | scoped CSS | Tailwind CSS | Tailwind CSS + 国风设计系统 |
| 布局 | 工具栏式 icon 按钮 | 左 rail + 侧栏 | **左侧星官栏 + 中央对话 + 右面板** |
| 动效 | Transition 基本 | Framer Motion 基本 | **Framer Motion + Three.js 星轨 + 粒子** |
| 设计语言 | 无 | 现代极简 | **国风水墨 + 毛玻璃 + 星官色系** |
| 游戏化 UI | ❌ | ❌ | **星官觉醒 / 沉睡石像 / 星轨路由 / 连珠特效** |
| 主题 | 单一暗色 | 暗色 + 浅色 | **昼夜变色（卯时暖黄 / 酉时深蓝）** |
| 音效 | ❌ | ❌ | **古琴单音（宫商角徵羽对应星官）** |
